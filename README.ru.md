# GremlinAmp

**Русский** · [English](README.md)

**Музыка любимых игр из Аркадного зала Школы Империи — на Android, в том числе без интернета.**

GremlinAmp — Android-приложение музыкальной библиотеки [Аркадного зала](https://games.oopssre.ru/gremlin.html). Выберите игру или серию, включите саундтрек или скачайте коллекцию на телефон. Постеры, состав серий и сведения об играх приложение получает из каталогов сайта.

Плеер оформлен в духе кассетного Walkman: ретрооблик сочетается с поиском, фильтрами и фоновым воспроизведением.

## Зачем он нужен

На сайте музыку можно слушать в браузере. GremlinAmp переносит эту библиотеку на телефон: позволяет слушать её в фоне, управлять воспроизведением с гарнитуры и брать скачанные коллекции с собой без интернета.

Например: найти любимую серию, выбрать игры нужной платформы, скачать их музыку и слушать в дороге. Короткие звуки можно скрыть фильтром длительности.

## Что в нём особенного

Приложение построено вокруг **игр и серий из Аркадного зала**:

- Игра — готовая музыкальная коллекция с постером; серия объединяет музыку входящих в неё игр.
- Поиск, алфавит и фильтры по платформам и годам используют сведения из существующего каталога.
- Игровые форматы NSF, SPC, VGM и другие воспроизводятся без предварительной конвертации в MP3. Отдельные композиции внутри одного файла учитываются как треки.
- Можно скачать музыку игры, серии или всей библиотеки. Общие файлы сохраняются один раз.
- При прослушивании сохраняется связь с игрой: название, постер и принадлежность к коллекции.

GremlinAmp предназначен прежде всего для слушателей сайта и любителей игровой музыки. Импорт произвольных папок с телефона сейчас не предусмотрен.

## Установка и первые шаги

Нужен **Android 8.0 или новее**. Поддерживаются ARM64, ARMv7 и x86_64. Текущая версия — **0.2.8**, интерфейс — на русском.

Ссылки на загрузку приложения размещаются в [медиатеке сайта](https://games.oopssre.ru/gremlin.html). APK также можно собрать из исходников по инструкции ниже.

1. Установите APK. При необходимости разрешите установку из выбранного браузера или файлового менеджера.
2. Откройте «Игры» или «Серии», найдите коллекцию и включите композицию.
3. Через меню коллекции скачайте музыку. Для прослушивания без сети откройте «Скачано».

Доступны очередь, перемешивание, повтор и перемотка, управление через уведомление и гарнитуру. Нажатие на миниатюру открывает постер с увеличением жестами. В настройках можно выбрать светлую, тёмную или системную тему. В разделе ресурсов и лицензий есть прямая ссылка на этот репозиторий GitHub.

Команда «Скачать все мелодии» находится в меню библиотеки и загружает всю музыку сайта независимо от фильтров. Для всей библиотеки и серий показывается подтверждение; объём указан, если он уже известен из сохранённых манифестов. Фильтр длительности позволяет скрывать короткие композиции и отдельно управлять треками с неизвестной длительностью.

## Скачивание и обновления

У коллекции одно действие: «Скачать», «Повторить» при ошибке или «Обновить» при появлении новой музыки. «Скачано» и ожидание сети показываются текстом. Прерванные запросы сохраняются и продолжаются автоматически; явная приостановка сохраняется до следующего запроса пользователя. Существующие аудиофайлы используются повторно.

В «Настройки → Сеть и автоматические обновления» можно включить автоматическое обновление скачанных коллекций: раз в час или раз в сутки после 07:00 по Москве. Android может откладывать фоновую проверку. Доступны «Только Wi-Fi» и «Wi-Fi и мобильная сеть»; настройка действует и при загрузке трека для прослушивания. Локальные файлы доступны без сети.

Можно следить за выбранными сериями или всей библиотекой сайта: при обновлении добавятся новые игры с музыкой. Эти подписки настраиваются в том же окне. По умолчанию автообновление выключено, загрузка разрешена только по Wi-Fi.

## После коллекции

Кнопка «После коллекции…» открывает режимы: остановиться, следующая игра серии, тот же жанр, похожие игры. Похожесть определяется по серии, жанру и платформе из каталога сайта; аудио не анализируется. Можно продолжать только скачанное. Уже прослушанные игры в пределах текущего сеанса очереди не повторяются, фильтры платформы, года и длительности сохраняются. Если подходящих игр нет, воспроизведение останавливается.

Перемешивание, повтор трека и повтор очереди находятся в том же окне. Повтор имеет приоритет перед переходом к другой коллекции. По умолчанию после коллекции плеер останавливается.

## Форматы

Игровые форматы воспроизводятся нативным [Game Music Emu](https://github.com/libgme/game-music-emu): NSF, NSFE, GBS, HES, SPC, VGM/VGZ, AY, SAP. Обычные аудиофайлы воспроизводятся средствами Android; на сайте сейчас также есть MP3 и OGG. Поддержка остальных обычных кодеков зависит от Android.

В файле игрового формата может находиться несколько композиций. Каждая композиция отображается отдельным треком.

## Сборка

Нужны Java 17, Gradle 8.13, Android SDK Platform 35, Build Tools 35.0.0, NDK 27.0.12077973, CMake 3.22.1, Python 3.8 или новее, Make, patch и `keytool`.

```bash
export ANDROID_SDK_ROOT=/path/to/android-sdk
export GREMLINAMP_STOREPASS=android
bash tools/build-sdk.sh
```

Результат: `build/GremlinAmp-0.2.12.apk`. Скрипт создаёт локальный тестовый ключ в `build/development.keystore`, если отдельный ключ не задан. Не помещайте ключи в Git.

Сборки для телефона и ТВ компилируют декодеры C и C++ из [архивов исходников](decoder-sources/README.md) через Android NDK. Аудиосервис обращается к библиотекам через JNI и передаёт PCM в Android AudioTrack. Игровая библиотека подключается через музыкальный API v1.

Чтобы выпускать обновления с одной подписью, задайте путь к своему закрытому ключу через `GREMLINAMP_KEYSTORE` и пароль через `GREMLINAMP_STOREPASS`. Скрипт использует alias `gremlinamp`.

Для сборки из командной строки используется SDK-скрипт. Gradle-проект также включён; Gradle Wrapper отсутствует.

Проверки модели состояния: `bash tools/test-state.sh`.

## Текущие ограничения

- У бесконечно повторяющейся игровой музыки нет единственной конечной длительности. Если конец не найден за 180 секунд ускоренного анализа, длительность остаётся неизвестной.
- Фильтр длительности не распознаёт назначение композиции: короткая музыкальная заставка тоже может попасть под него.
- Нет отдельного экрана удаления скачанных коллекций.
- После принудительной остановки Android загрузку надо запустить повторно; уже загруженные и частичные файлы сохраняются.
- APK текущей серии подписаны ключом разработки. Не заменяйте ключ при подготовке обновления для уже установленных приложений.

Обновление приложения открывается из меню библиотеки. Ручная проверка скачивает новую версию и открывает установщик Android, пока окно обновления активно. Уже скачанный APK можно установить кнопкой «Установить обновление». Автоматическое скачивание можно включить раз в час или раз в сутки после 07:00 МСК и разрешить мобильную сеть. Проверку APK и подтверждение установки выполняет Android.

Продолжение по музыке: «По ритму» и «По звучанию» используют серверный анализ после завершения текущей очереди. Учитываются фильтры, история и режим «только скачанное». Индекс сохраняется в локальную базу для офлайна; его отсутствие на сайте не мешает обычному воспроизведению. Обновление — общей командой «Обновить библиотеку».

Недоступные музыкальные режимы неактивны с указанием причины до выбора. Повтор трека и очереди взаимоисключающие; при повторе продолжение приостановлено. Проверка индекса показывает загрузку и защищена от повторного запуска.

VGM/VGZ с YM2413 воспроизводятся через включённый emu2413 (MIT) и локальный адаптер. Проверка tools/test-ym2413.py создаёт собственный VGM только с YM2413 и проверяет звук через собранную для компьютера libgme.


В 0.2.7 постеры и миниатюры входят в загрузку коллекции. Недостающее оформление ранее скачанной музыки заполняется автоматически по выбранной сети, без повторной загрузки звука. Картинки сопоставляются по ссылке карточки и стабильному RA ID; сохранённый полный постер может заменить миниатюру. Отдельных команд для офлайна, постеров или индекса анализа нет.

После прерванного обновления вкладка «Скачано» использует последний полностью сохранённый треклист. Открытие приложения сначала показывает локальный каталог, затем проверяет обновления. Акустический индекс необязателен для обычного воспроизведения; ранее загруженный индекс работает без сети.

«Назад» и «Вперёд» проходят историю фактически запущенных треков, включая перемешивание и переход между играми. Продолжение добавляет треки к очереди. Недоступные файлы пропускаются с ограничением числа попыток; завершение очереди освобождает аудиоплеер. Загрузка картинок и измерение длительности не задерживают старт скачанного звука.

Главный экран содержит воспроизведение, разделы библиотеки, поиск и один фильтр. Скачивание всей библиотеки и общая проверка обновлений находятся в меню; сеть и автоматические обновления — в общих настройках. Постер открывается по нажатию на картинку. Возврат из треклиста восстанавливает серию или раздел «Скачано» вместе с поиском. Обновление каталога сохраняет активный экран.


### Переход на музыкальный API v1

Игры и состав серий читаются из `/music/game-index.json`, глобальный поиск треков и картинки используют медиатеку сайта. При недоступности нового индекса используется ранее проверенная копия v1. Старые игры в каталог v1 не подмешиваются.

«Скачать все мелодии» загружает ZIP по квитанции `/music/library.json`. После обрыва плеер продолжает скачивание с сохранённого байта, если SHA-256 в квитанции совпадает. Если сервер заменил ZIP, плеер скачивает новую версию по тому же адресу с начала. Старая офлайн-библиотека доступна до проверки размера и SHA-256 нового ZIP, распаковки и проверки каталога. Команда «Удалить скачанную музыку» очищает офлайн-библиотеку, отдельно загруженные игры, их постеры и очередь загрузки.

## Радио и очередь

«Радио» открывается из меню библиотеки и играет в том же плеере, что и музыка игр. Радио работает в фоне и учитывает настройку сети. В релизной сборке личные станции открываются кодом в «Настройки → Личный режим». При сборке из исходников список берётся из локального `app/src/main/assets/personal-radio.json`. Это массив записей с полями `title` и `url` (HTTPS). Git игнорирует этот файл.

Если уже играет серия, открытие другой серии заменяет очередь, когда её треки готовы. Внутри серии можно запустить очередь кнопкой «Играть серию». Режим «По всей библиотеке» включает игры вне серий и учитывает фильтры и настройку «Продолжать только скачанное». Индекс анализа обновляется отдельно от каталога игр. Его статус и обновление доступны в настройках очереди.

## GremlinAmp TV

Модуль `tv` собирает отдельное приложение для Android TV. Выполните `gradle --configure-on-demand :tv:assembleRelease`. Минимальная версия Android — 8.0. Модуль ТВ использует те же нативные декодеры, что и телефон.

Игры, серии и интернет-радио открываются с пульта. В списке инверсная строка со знаком `>` показывает фокус, а `▶` отмечает играющий трек или его игру. Кнопка «После очереди» задаёт, что играет после последней композиции. Здесь же можно проверить или обновить серверный индекс для режимов «По ритму» и «По звучанию». При переходе к другой игре треклист переключается на неё. «Предыдущий» возвращает к прослушанной композиции и её треклисту. При выходе с экрана приложения воспроизведение останавливается.

Поиск показывает отдельные композиции и подписывает их происхождение. Можно совместить текст запроса, платформу, серию и происхождение. Текст ищется в названии трека, игры, серии, платформы и имени исполнителя. Запрос вида «RA:11684» ищет точный ID игры. Если оставить строку пустой, работают выбранные фильтры. ОК на результате открывает треклист игры и запускает найденную композицию.

В «Настройки → Оформление» можно выбрать тёмный «Терминал» или светлую «Бумагу». Тема сохраняется. Личные станции открываются прежним кодом в «Настройки → Личный режим», если в сборку включён локальный список станций.

Плеер использует системный прокси Android TV для радио, музыкального каталога и обновлений. После изменения прокси заново запустите станцию. Если прокси требует авторизацию или отклоняет запрос, плеер показывает причину и предлагает повторить.

В каталоге или треклисте нажмите вправо, затем ОК, чтобы открыть визуализацию. «Назад» восстанавливает строку и прокрутку списка. Музыка продолжает играть во время переходов. В визуализации стрелки влево и вправо меняют сцену, вверх открывает список сцен, вниз переключает трек. ОК ставит музыку на паузу или возобновляет её. Если музыка не выбрана, ОК открывает список сцен. «Астероидное поле» рисует векторную заставку, которая реагирует на звук. Tennis for Two воспроизводит координаты мяча из [записи розыгрыша](https://github.com/GremlinEngineering/tennis-for-two/blob/ae5294e599881d4d9de5897fb047b5b8238bb1e0/app/demo/manifest.json) проекта Лаборатории. В списке также есть три фрактала.

При проигрывании серии следующие исходные файлы предзагружаются в RAM. Лимит 30 000 000 байт учитывает текущие, подготовленные и ещё загружаемые файлы. Один файл, общий для нескольких треков, занимает буфер один раз. Меню «Кэш» показывает объём RAM-буфера и служебных файлов в папке кэша приложения. Очистка RAM отменяет предзагрузку, текущий трек доигрывает. Очистка диска работает с папкой кэша приложения. Музыкальная библиотека на диск не записывается.

В «Настройки → О приложении» указаны версия, автор и ссылки на сайт и исходный код. Откройте «Обновление приложения», чтобы проверить обновление вручную. При открытом плеере проверка выполняется раз в день после 07:00 по Москве. «Обновить» скачивает APK и открывает системный установщик Android. Если окно закрыли, скачанный APK можно установить при следующем открытии этого раздела. Для первой установки из плеера может потребоваться системное разрешение на установку приложений.
