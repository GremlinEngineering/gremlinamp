# GremlinAmp для macOS

Музыка Аркадного зала Школы Империи на Mac. Версия 0.2.1 использует
светлую и тёмную тему «Терминал» с боковой навигацией macOS.

В разделе «Трекер» девять непрерывных генераторов. Шестерёнка у режима
открывает его параметры, кнопка в плеере — параметры активного режима.
«Погода» использует опубликованный срез «Затонувшей чайной», «Орбиты» —
данные JPL и NOAA. При потере сети генераторы работают по сохранённому
срезу или встроенному архиву. Таймер сна настраивается с шагом в пять минут.
Личный режим радио открывается прежним кодом, если при сборке в
`Resources/personal-radio.json` присутствует список станций.

Для локальной сборки с личным радио рядом с `Resources/personal-radio.json` положите `Resources/personal-radio.sha256` с SHA-256 кода без пробелов по краям, строчными буквами.

## Сборка и установка

Нужна macOS 12 Monterey или новее. Для сборки — Command Line Tools 14 или
новее с macOS SDK 13+ и Swift 5.7+. Homebrew, CMake и скачивание библиотек не требуются.
Если инструменты Apple ещё не установлены, выполните `xcode-select --install`.

1. Распакуйте архив.
2. В папке `GremlinAmp_Mac` выполните:

   ```bash
   bash build-macos.sh
   ```

3. В папке `build` появятся `GremlinAmp.app` и DMG для архитектуры вашего Mac.
4. Откройте DMG, перетащите приложение в Applications и извлеките образ.
5. Запустите GremlinAmp из Applications.

Для сборки сразу под Apple Silicon и Intel:

```bash
GREMLINAMP_ARCH=universal bash build-macos.sh
```

Сборка подписывается локальной подписью. Сертификат Developer ID и нотариализация
Apple в комплект не входят. macOS может потребовать разрешить первый запуск
через «Открыть» в контекстном меню приложения.

## Музыка

- Игры и серии с музыкой, постерами, поиском, алфавитом, фильтрами платформы и года.
- Очередь, перемотка, перемешивание, повтор композиции и повтор очереди.
- Фильтр коротких композиций: 5, 10 или 15 секунд; отдельный режим неизвестной длительности.
- «Скачать всё» сохраняет всю музыку сайта независимо от поиска и фильтров.
  Перед началом показывается объём недостающей музыки; уже загруженные файлы
  и сохранённая часть докачки вычитаются. Постеры скачиваются дополнительно.
- Скачивание игры, серии или выбранных игр. Общие файлы сохраняются один раз,
  содержимое проверяется по SHA-256. Повтор запроса продолжает сохранённый `.part`.
- «Скачано» открывает сохранённые коллекции. Каталог и постеры кешируются.
- Состояния коллекций: «Скачать», «Докачать», «Сохранить» (все файлы уже в кеше),
  «Скачано» и «Есть обновления». Сохранённые коллекции с новыми файлами остаются
  в разделе «Скачано» с отметкой обновления.
- Автообновление сохранённой музыки: каждый час или ежедневно после 07:00 МСК.
  Можно следить за новыми играми отдельных серий или всей медиатеки.
- После очереди: остановка, следующая игра серии, тот же жанр, похожие игры,
  подбор по ритму или звучанию. Учитываются платформа, год и длительность.
  По умолчанию продолжение использует только скачанную музыку.
- Настройки очереди объединены в одном разделе. Повторы композиции и очереди
  исключают друг друга и имеют приоритет перед продолжением. Перемешивание
  обходит каждую запись очереди один раз за проход.
- Воспроизведение после закрытия окна. Меню в строке macOS, медиаклавиши,
  сведения о композиции в системном управлении воспроизведением.
- Системная, светлая или тёмная тема. Прямая ссылка на GitHub в «О проекте».

## Настройки приложения

Откройте «Настройки» в боковой панели или нажмите `⌘,`.

- «Приложение → Запускать GremlinAmp при входе в macOS» управляет автозапуском.
  На macOS 13+ используется системный Login Item. Если macOS запросит разрешение,
  рядом появится кнопка системных настроек. На macOS 12 используется LaunchAgent
  текущего пользователя. По умолчанию автозапуск выключен.
- «Музыка» управляет расписанием и подписками. Ручная проверка сохранённого
  доступна независимо от автоматического расписания.
- «Очередь» управляет повтором, продолжением и индексом анализа музыки.
  Ритм и звучание доступны при наличии на сайте `assets/music-similarity.json`
  формата Android 0.2.5 (`schema_version: 1`, `tracks`, `refs`, `neighbors`).
  При отсутствии индекса, анализа текущего трека или соседей опция отключена
  с объяснением. Индекс кешируется атомарно и работает без сети; ошибка загрузки
  сохраняет предыдущий пригодный индекс. Размер JSON ограничен 128 МиБ.
- «Обновления клиента → Автоматически скачивать обновления клиента» — отдельная
  опция, по умолчанию выключена. Поддерживаются почасовая и ежедневная проверки.
  После загрузки и проверки размера/SHA-256 появляется кнопка открытия DMG.
  Установка выполняется пользователем через замену приложения в Applications.
- По умолчанию загрузки используют Wi-Fi и Ethernet. Можно отдельно разрешить
  сотовую и ограниченную сеть; настройка действует на все сетевые загрузки.

Расписания работают, пока приложение запущено, в том числе с закрытым окном.
После сна пропущенная проверка выполняется при возобновлении работы приложения.
При завершённом GremlinAmp проверок нет. Опция автозапуска позволяет возобновлять
их при входе в macOS. Запуск приложения сам по себе не включает воспроизведение.

## Публикация обновлений macOS

Сборка создаёт `build/macos-release.json` рядом с DMG. Для работы обновлений
нужно опубликовать этот JSON по адресу
`https://games.oopssre.ru/assets/arcade/music-app/macos-release.json`, а сам DMG —
в `assets/arcade/music-app/macos/` на том же сайте. Скрипт не публикует файлы.

JSON содержит номер сборки, версию, минимальную macOS, идентификатор приложения,
размер и SHA-256 DMG для arm64, x86_64 или universal. Если в той же папке build
собрать вторую архитектуру той же версии, её запись добавится в существующий JSON.
Для нового релиза увеличьте `CFBundleVersion` и `CFBundleShortVersionString`
в `Resources/Info.plist`; номер сборки сравнивается численно.

Клиент принимает HTTPS-ссылки только с `games.oopssre.ru`, проверяет архитектуру,
минимальную macOS и целостность файла. При временной недоступности релиза или
ошибке докачки отображается причина; повтор использует сохранённую часть DMG.

Обычные форматы музыки из каталога: MP3, AAC/M4A (включая ALAC при поддержке системного декодера),
WAV, AIFF, AIFC, CAF, FLAC — AVFoundation. OGG/OGA Vorbis — stb_vorbis.
Защищённые DRM-файлы и Ogg Opus не поддерживаются.

Игровые форматы: NSF, NSFE, GBS, HES, SPC, VGM/VGZ, AY, SAP, KSS, GYM — Game Music Emu.
FM-звук YM2413 в VGM/VGZ воспроизводится включённым ядром emu2413 (MIT).
Композиции внутри одного игрового файла отображаются отдельными треками.
Для музыки без тайминга выполняется анализ до 180 секунд ускоренного звука.
Если конец не найден, длительность показывается неизвестной, а проигрывание
использует ограничение из каталога.

Отмена скачивания останавливает очередь после текущего файла. Файлы, которые
загружались для прослушивания, сохраняются в кеше; отметка «Скачано» появляется
после полного скачивания коллекции. Отдельного экрана удаления коллекций пока нет.

## Разработка

Код интерфейса: SwiftUI / AppKit, аудио: AVFoundation / AVAudioEngine.
Game Music Emu и stb_vorbis включены в `Vendor`, C-мост находится в `Native`.

Перед компиляцией звуковых библиотек скрипт проверяет Swift-код компилятором
Apple. После сборки запускаются проверки правил очереди и фильтров, а также
проверки расписания, выбора обновлений, состояний коллекций, докачки и
подбора по сохранённому индексу. Затем выполняются
проверка декодера YM2413 и звукового тракта AVAudioEngine на синтетических
тонах NSF, VGM/VGZ (PSG и YM2413) и OGG
при 44,1 и 48 кГц. Проверка работает без вывода на колонки: при тишине
или ошибке аудиографа сборка останавливается до создания DMG.
Переносимые проверки нативного декодера на Linux/macOS:

```bash
bash tools/test-native.sh
```

Данные хранятся в `~/Library/Application Support/GremlinAmp`.
Настройки — в домене `ru.oopssre.gremlinamp.mac`.
Это самостоятельное приложение с собственными данными.

Начиная с 0.2.2 дополнительные нативные декодеры собираются из тех же
зафиксированных исходников, что и в GremlinAmp для Android. Для сборки
нужны Python 3 и CMake 3.22+, Ninja используется при наличии. В репозитории GitHub запускайте `bash macos/build-macos.sh` из корня.
Скрипт берёт исходники из `decoder-sources/archives/` и общие фронтенды из
`app/src/main/cpp/`. Для локальной раскладки с отдельными папками
`GremlinAmp_Mac` и `GremlinAmp` скрипт также находит Android-проект рядом.
Адаптация под macOS выполняется в папке сборки. Оригинальные исходники и их лицензии остаются в этих архивах.

В плеере переключатель «Трекер для очереди» применяет выбранные стиль
и длину ко всем трекам очереди. Аранжировка строится локально по мотиву
исходного трека, сохраняет перемотку и занимает временный файл только
на время воспроизведения. Если мотив выделить не удалось, играет оригинал.
PSF2, как и на Android, играет через готовый WAV из каталога при его наличии.
