# GremlinAmp 0.1.7 — первая тестовая сборка

Android 8.0+; ARM64, ARMv7, x86_64. Отдельный плеер игрового блога.
Название в интерфейсе: «Музыка Аркадного зала». Иконка — кассетный плеер с ключом. Доступны системная, тёмная графитовая и светлая серебристая темы.

## Установка

Установить GremlinAmp-0.1.7.apk. Разрешить уведомления, чтобы видеть управление и загрузки.
Пользователь подтвердил воспроизведение NSF в предыдущей версии. В этой версии исправлена гонка при переключении треков. Повторная проверка на физическом Android пока не выполнена. Попытка проверки эмулятором прервана сбоем самого эмулятора до запуска приложения.
APK подписан ключом разработки. Это не выпуск для Google Play.

## Что реализовано

- Каталог и поиск игр из assets/gallery-music.json.
- Существующие music/sets/*.json: subsong, порядок, play_ms и fade_ms.
- NSF, NSFE, SPC, VGM/VGZ, HES, GBS, AY, SAP через нативный Game Music Emu.
- MP3, OGG и обычное аудио через Android MediaPlayer; поддержка дополнительных кодеков зависит от Android.
- Фоновое воспроизведение, MediaSession, уведомление, аудиофокус, пауза при отключении проводной/BT-гарнитуры.
- Очередь выбранной игры/серии, предыдущий/следующий трек, перемешивание, повтор одного (REPEAT 1) и очереди (LOOP).
- Постер игры из views.poster, с существующей иллюстрацией как запасным вариантом; локальная копия и обложка MediaSession.
- Загрузка игры, серии или всей библиотеки; предварительный размер недостающей музыки.
- SHA-256 при загрузке, дедупликация, HTTP Range для продолжения частичного файла, фоновый сервис скачивания, отмена.
- Законченные загрузки сохраняются после закрытия приложения; раздел «Локально».
- Музыка загружается в исходном опубликованном формате, без перекодирования. Для проигрывания файла с сайта сначала скачивается этот файл.

После принудительной остановки Android загрузку нужно запустить повторно: проверенные файлы используются заново, частичный файл продолжает загрузку. Автоматического запуска после перезагрузки нет.
Обложки берутся из кеша; смена постеров на сайте пока не обновляет сохранённую обложку автоматически.
Добавлены перемотка, алфавитный фильтр, подсветка текущего трека, увеличение постера (щипок, перенос, двойное касание для сброса), экран ресурсов и лицензий с полным текстом LGPL. Интерфейса удаления коллекций пока нет. Системная очистка данных удалит локальную библиотеку.

## Данные сайта

Изменять сервер не требуется. Серверные файлы в этой поставке отсутствуют.

- assets/gallery-music.json: существующие игры и музыкальные коллекции.
- music/sets/*.json и music/files/*: треки, внутренние композиции, музыка.
- assets/gallery-games.json: постеры игр.
- assets/statistics.json, поле series: названия серий и готовый состав members.

Связь members[].ra_id → музыкальная коллекция game-ra-ID. Сопоставления по названию и разбора HTML нет. Сохраняется порядок из members; одинаковые коллекции не повторяются. Игры без готовой музыки не включаются в очередь и скачивание серии. Каталог серий кешируется целиком и читается без сети после первого успешного получения.

## Сборка

Основной проверенный путь без Maven/Gradle-зависимостей:

```bash
export ANDROID_SDK_ROOT=/path/to/android-sdk
export GREMLINAMP_STOREPASS=android
bash tools/build-sdk.sh
```

Нужны Java 17, SDK platform/build-tools 35, NDK 27.0.12077973, CMake 3.22.1, zip и keytool. Результат: build/GremlinAmp-0.1.7.apk.
Для сохранения подписи следующих тестовых сборок используйте build/development.keystore:

```bash
export GREMLINAMP_KEYSTORE=build/development.keystore
```

Это только тестовый ключ, его пароль android. Для публичного выпуска создайте отдельный закрытый ключ.
В комплекте также Gradle-проект (AGP 8.7.3, Gradle 8.9), но APK собран скриптом tools/build-sdk.sh.

## Проверки

Java-код компилируется против Android API 35. JNI/C++ собран для трёх ABI.
APK прошёл проверку подписи v2/v3 и выравнивания ZIP; ELF библиотеки собраны с размером страницы 16 КиБ.
Существующий Game Music Emu из комплекта сайта на хосте декодировал по 5 секунд реальных NSF, SPC, VGM, HES и GBS; входные SHA-256 совпали с опубликованными манифестами. MP3 и OGG декодированы на хосте FFmpeg.
Проверены готовые JSON-связи серии 194X и сопоставление по ra_id.
Это проверки сборки и файлов, а не подтверждение воспроизведения и жизненного цикла сервисов на Android.

## Исправления 0.1.7

AudioTrack теперь создаётся, управляется и освобождается только в потоке декодирования; главный поток отменяет старое задание через generation, не обращаясь к освобождаемому AudioTrack. MediaPlayer не получает pause/start до завершения prepareAsync. Старые callbacks не меняют новый трек. Повтор одного трека применяется при естественном окончании, ручная кнопка «Следующий» переходит дальше. Разделены состояния загрузки, воспроизведения, паузы, ошибки и завершения очереди. Ошибка не заменяется сообщением о скачивании. Перемотка GME выполняется в том же потоке, что декодирование. При изменении экрана устаревший асинхронный треклист не заменяет новый экран.

Идентификатор пакета и тестовая подпись сохранены; можно обновить поверх 0.1.1. Сервер не изменяется.

Оформление 0.1.7: кассетная иконка, панель с катушками, положение которых связано с фактическим временем трека. Иконки транспорта выполнены в векторе. Минимальные зоны основных кнопок 48 dp. Постер увеличивается отдельным просмотром.

0.1.7: добавлены PNG launcher-иконки пяти плотностей и адаптивная иконка Android; icon/roundIcon и иконка MainActivity привязаны к mipmap/ic_launcher. Проверено содержимое собранного APK, ресурсные ссылки и подпись.

## Изменения 0.1.7

Единые карточки игр и серий: одинаковая область изображения, FIT_CENTER, заголовок, сведения, меню. Миниатюры и полные изображения получаются из существующих gallery-games.json и gallery-series.json, без угадывания путей. При наличии views.poster используется его src/preview, иначе готовое src. Нажатие на миниатюру открывает полный постер. Внутри серии доступен её постер, при проигрывании обложка соответствует игре. Полные изображения и миниатюры кешируются. Сохраняется доступ к обложкам, скачанным предыдущими версиями.

Внутренние диалоги используют тему приложения: фон, текст, акцент и рамки. Системные разрешения, уведомления и внешние браузеры остаются в управлении Android.

Подключён gme_track_ended(). Неизвестная длительность больше не отображается как точные 02:00. Перед первым проигрыванием скачанного неизвестного игрового трека и при скачивании коллекции выполняется измерение до 180 секунд ускоренного декодирования, с отключённым метаданным лимитом GME. Последний блок звука измеряется с шагом 0.1 секунды и порогом RMS 16. Результат — оценка, а не доказанная семантическая классификация музыки. Если конец не найден, точная длительность остаётся неизвестной. Результат хранится локально по SHA-256 и subsong, с версией методики v1. Ничего не перекодируется в постоянные аудиофайлы.

Меню «Скрывать короткие звуки»: всё / короче 5 / 10 / 15 секунд. Фильтр использует известные или измеренные длительности; неизвестные остаются. Он действует на список, создание очередей и автоматические переходы. Защита от бесконечного перебора, если все треки скрыты. Долгое нажатие на трек показывает источник и статус длительности.

Проверка JNI на хостовой JVM: NSF 1942, subsong 5 — звук около 700 мс, сигнал окончания около 1700 мс; subsong 0 не завершился за 180 секунд, не объявлен конечным. Проверено чтение Gme.ended в цикле реального декодирования. Java компилируется против Android API 35, JNI собран для трёх ABI, проверена подпись APK. Интерфейс этой версии и жизненный цикл на Android пока не проверены на устройстве.

0.1.7: фильтр коротких звуков вынесен рядом с поиском, скачивание — рядом с заголовком библиотеки. Тема, обновление и ресурсы находятся в явных «Настройках». Троеточие строки содержит только действия с конкретной игрой/серией. Переключение режимов очереди сохраняется без запуска фонового сервиса до выбора музыки.

0.1.7: платформы и годы доступны отдельными кнопками рядом с фильтром длительности. Метаданные берутся из statistics.json.editions по ra_id и соединяются с музыкальными коллекциями по ID. Серии без музыкальных игр скрыты; число игр серии учитывает платформу и год. Настройки фильтра неизвестной длительности: показывать / скрывать / только неизвестные. Действие скачивания библиотеки учитывает показанные игры, поиск и алфавит. Кнопка «Сбросить» снимает фильтры.

## 0.1.7 — согласованное состояние проигрывателя и MIT

Панель текущего трека использует единый PlaybackIdentity: название, игра и обложка относятся к одному поколению запуска. Старый постер очищается сразу. Просмотр другой игры больше не записывает постер в панель воспроизведения. Запоздавшие ответы отвергаются. При отсутствии нового постера остаётся пустая область, а не изображение прошлой игры. Очереди, подготовленные после нового выбора пользователя, не заменяют его.

Известная длительность в списке и плеере включает затухание. Положение ограничивается общей длительностью. Асинхронные изменения времени и состояния применяются в главном потоке с проверкой поколения трека. Сам AudioTrack остаётся исключительно в потоке декодирования.
