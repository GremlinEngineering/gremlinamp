# Выпуск версий

1. Обновить versionName/versionCode в app/build.gradle, а также соответствующие параметры и имя результата в tools/build-sdk.sh. versionCode должен расти.
2. Выполнить tools/test-state.sh и сборку для трёх ABI.
3. Использовать прежний закрытый ключ подписи для обновлений установленного приложения. Ключ и пароли не входят в Git, ZIP исходников и GitHub Actions artifacts.
4. Проверить запуск и сценарии Android: игра → серия, следующий/предыдущий, пауза при загрузке, экран блокировки, гарнитура, отключение сети, возобновление скачивания, темы и постеры.
5. Проверить подпись APK средствами apksigner. Не считать одну компиляцию подтверждением всех действий на устройстве.
6. Создать тег версии и GitHub Release. Прикрепить подписанный APK и ZIP соответствующих исходников. Ключ подписи не публиковать.
7. Рядом с APK сохранять доступ к соответствующим исходникам Game Music Emu и приложения для пересборки и перелинковки.
8. Обновить версию/имена APK и Source ZIP в серверном release.json; source_url должен указывать на фактический репозиторий.

CI по умолчанию создаёт APK с новым временным тестовым ключом. Он нужен для проверки сборки и не заменяет подписанный релиз: такой APK может не устанавливаться поверх официальной сборки.
