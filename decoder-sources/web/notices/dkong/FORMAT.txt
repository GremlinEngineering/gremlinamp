Bytes68..127 zero. Program then externaldata then8byte events:

Program/data are unmodified original sound firmware/tables, not full game
graphics or rendered songs. Events are original game writes observed at actual
MCU instruction boundaries. P1 feeds DAC, P2bit7 the original discharge circuit.
Each graph sample advances at floor(cycle*48000/400000) before the pin change.

All28 used mathematical node classes and both complete component graphs are
pinned original MAME excerpts, including the original custom DK mixer.
DAC stream transport and scheduling are standalone glue; music-only effects
inputs held at reset. VR2=90, original route gainsDK0.9/DKJR0.5.
Linear rational resampling to8–192kHz; output is zero after bounded duration.
Pinned CPU EA/IRQ implementation limitations retained. No analog-board
measurement, full game sound effects, or oldMP3 waveform equivalence claimed.
